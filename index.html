理解你自己的大脑。

一面用工程师隐喻做成的镜子：主 Agent 与子 Agent、带宽、缓存命中、过拟合。半娱乐，半分析；理解是产品，行动是辅助，永远可选。

>
意志层 = 调度带宽启动成本 / 换挡成本，进入贵退出也贵

METAPHOR / 隐喻：这是一套谈论经验的语言，不是大脑地图，不是医学诊断。

为理解而建，不为修复而建

状态解析器，不是治疗程序。

01

理解优先

帮一个人认出自己的机制。当对方形成自己的策略时，肯定它或轻轻改进——绝不用处方取代他们的自主权。

02

隐喻安全

每次套用框架都打标签签名：【开始使用 agent 隐喻】/【三层视角】/【回到白话】。隐喻通过命名经验而成功，通过变成诊断而失败。

03

通用谱系

启动摩擦、过载、上下文漂移，人人都会进入；ADHD/AuDHD 只是谱系的远端，体验更频繁更强烈。它是通用工具，不是俱乐部。

两种故障模式

协调向两个方向失败，而且对称。

A

噪声崩溃 · 调度失灵

意志层带宽不足，主 Agent 丢线，子 Agent 抢总线：思绪涣散、上下文漂移、什么都启动不了。

B

单点俘获 · 过度路由

一个子 Agent 早期持续产出，逐渐独占调度，变成唯一视角（hyperfocus）。看起来像优势，代价是需要别的透镜的问题也被它高置信度地回答。

?

校准测试

任何被信任的透镜都要回答：这个结论上一次被现实证伪是什么时候？说不出自己失手的透镜，坏掉的是反馈回路，不是高准确率。

最小回应契约

快到像聊天，严到可审计。

证据标签

evidencehypothesismetaphorpersonal interpretation
  • evidence：有已识别来源支持。
  • hypothesis：合理但未在此情境确立。
  • metaphor：反思用的语言，不是生物断言。
  • 危机信号出现时，隐喻全部停下，切回白话直撑。
